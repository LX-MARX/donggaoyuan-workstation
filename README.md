# 东高垣数字治理工作站（网站）

「沐光共富 Solar Common」品牌站点之一，屋顶上的共富路项目组出品。以陕西省渭南市大荔县段家镇东高垣村整村光伏实证为基础，面向政府、企业、村集体、农户提供政策检索、项目申报、数据看板与预约调研等数字治理工具。

## 访问方式

**线上访问（推荐）**：本站已通过 GitHub Pages 上线，浏览器直接打开即可，无须下载安装。

**本地浏览**：下载本仓库后，在本目录运行任意静态服务器（如 `python -m http.server 8080`）后访问 `http://localhost:8080/`。全部样式、脚本、数据均本地化，无外部依赖。

## 技术架构

**静态前端＋Supabase 云数据库＋离线缓存回退**：

- 前端为原生 HTML＋CSS＋JS（无框架、无外部 CDN），每页一个 IIFE 内联脚本，共享 `assets/js/main.js` 与数据层 `assets/js/data.js`。
- 云数据库为 Supabase（PostgreSQL＋PostgREST），通过 `assets/js/api.js`（window.MG）直连：政策库、项目库、看板指标实时读取，预约登记实时写入；匿名密钥配合行级安全策略（RLS）使用，数据表只读、预约表只可写入。
- 连接配置在 `assets/js/config.js`（window.MG_CONFIG）；留空即为离线模式。
- 所有动态化均为「库优先＋本地兜底」：接口失败或未配置时返回 null，页面自动回退 `assets/js/data.js` 中的离线缓存（口径与云端一致），并显示「离线缓存模式」徽标，演示永不中断、不白屏。

## 数据口径声明

- 东高垣村数据：2026 年 2 月企业访谈与入户访谈口径。
- 全县数据：均标注「大荔县全县（含东高垣村），截至 2025 年 7—8 月企业台账」。
- 看板指标由云端数据库实时下发；离线时显示本地缓存口径，两者数值一致。
- 数据看板的 3D 地形为艺术化数据地形（装饰性可视化），峰峦起伏仅作视觉隐喻，不对应具体分区数值，真实指标以数据卡为准。
- 企业与人物均按调研规范匿名化；示意模型与预测类内容均已明确标注，不与实测数据混用。

## 互链关系

本站与姊妹站「屋顶上的共富路——整村光伏建设方案」（https://lx-marx.github.io/gongfulu/）互相引用：`assets/js/main.js` 注入的导航「相关方案」链接、页脚「相关方案」栏目与页脚链接共 3 处指向该站；两站共用同一 Supabase 数据库（gf_ 前缀表与共富路站对应，ws_ 前缀表与本站对应，预约表按 site 字段区分来源）。
